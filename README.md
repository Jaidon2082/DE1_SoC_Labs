# DE1-SoC Labs

FPGA/embedded labs from Embedded System Design 1, targeting the Terasic DE1-SoC board (Cyclone V) in Intel Quartus Prime, with Nios II soft-processor software where applicable.

| Lab | Description |
|---|---|
| [Lab 1](DE1_SoC_Lab1) | `lightsNoNios` — pure VHDL design (no Nios II processor) driving the LEDR LEDs from the KEY pushbuttons. |
| [Lab 3](DE1_SoC_Lab3) | Nios II system (`nios_system.qsys`) running a timer + pushbutton interrupt demo: KEY1 ISR adjusts the HEX display, a timer ISR toggles LEDs periodically. |
| [Lab 4](DE1_SoC_Lab4) | Custom `servo_controller` VHDL component (Avalog-MM style peripheral) generating a servo PWM waveform, with a VHDL testbench. |
| [Lab 5](DE1_SoC_Lab5) | Nios II system integrating the custom `servo_controller` hardware component (via `servo_controller_hw.tcl`) with C software to control it. |

## Notes

- Only hand-written source is tracked: VHDL (`.vhd`), pin/project files (`.qsf`/`.qpf`), the Qsys system definitions (`.qsys`/`.sopcinfo`), Nios II C source, and scripts. Quartus/Nios II build output (`db/`, `incremental_db/`, `output_files/`, generated BSPs, synthesis files, compiled binaries, etc.) is excluded via `.gitignore` since it's fully regenerated by the toolchain from the source files above.
- Open a lab's `.qpf` in Quartus Prime to rebuild it; Nios II software projects can be regenerated with the included `create-this-app` script plus the Nios II BSP tools.
